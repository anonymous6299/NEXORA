# NEXORA – Personalized News Reading Platform

NEXORA is a web application for discovering, summarizing, saving, and organizing news articles with offline reading and personal notes.

## Features
- News search and filters by topic, date, language, and country
- Personalized article recommendations
- AI-based article summarization using OpenRouter API
- Read Later and offline access
- Personal notes for articles
- Minimal black-and-white interface

## Tech Stack
React.js, JavaScript, HTML5, CSS3, Tailwind CSS, Heroicons, FreeNewsAPI, OpenRouter API, Local Storage.

## Installation
```bash
git clone https://github.com/anonymous6299/NEXORA
cd nexora
npm install
npm run dev
```

Configure your FreeNewsAPI and OpenRouter API keys before running the application.
